System architecture

 Float sensors (1/2/3 ft)         Village gateway          Cloud (this page's backend)
┌────────────────────────┐  LoRa   ┌──────────────┐  MQTT   ┌──────────────────────────┐
│ River node   ESP32+SX1278├───────►│ Master  ESP32├────────►│ Public broker (demo)     │
│ GPS · solar · battery   │  433MHz │ WiFi backhaul│         │   ↓ parser               │
│ self-healing LoRa mesh  │◄───────┤ CAD · seq ACK│◄────────┤ MongoDB Atlas + Redis    │
└────────────────────────┘  cmds   └──────────────┘  cmds   │   ↓ this API             │
                                                            │ REST + SSE → website     │
                                                            └──────────────────────────┘
  • Reliable delivery — every transmission is ACKed per hop and retried with jitter until acknowledged.
  • Latest-wins freshness — alerts carry a monotonic seq: a level-2 alert always overtakes an in-flight level-1.
  • Channel discipline — LoRa is half-duplex; every transmit is preceded by a channel-activity scan (CAD) with random backoff.
  • Self-healing mesh — nodes discover parents by signal quality; a lost parent is re-discovered in seconds, and offline reports are suppressed if the node already re-announced elsewhere.
  • CI/CD — this page and its backend deploy automatically from GitHub to the droplet on every push.
